# Binkām

Minuteur de séries pour la salle (notification + vibration + son à la fin de chaque série, même téléphone verrouillé). Un seul écran : durée, nombre de séries, cercle de décompte avec de l'eau qui baisse (appui au centre = GO / fin de série), tirets de progression, et trois boutons : son, notifications, écran allumé.
Hors ligne, sans compte, sans connexion réseau (les réglages restent sur l'appareil).

```
npm install
npm start        # puis Expo Go, ou « w » pour le navigateur
npm test         # logique du minuteur + règles de la palette
npm run typecheck
```
